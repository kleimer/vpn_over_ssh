# SSHTUN: ваш пополняемый список исключений (идут НАПРЯМУЮ, мимо туннеля)
# Формат: одна подсеть или адрес на строку, адрес — с /32.
# Комментарии (#) и пустые строки игнорируются.
#
# Добавлять можно вручную сюда или командой (применит сразу, без перезапуска):
#   sshtun exclude add 203.0.113.0/24
#   sshtun exclude add 198.51.100.7
#
# Целые AS и страны — через автогенные списки:
#   sshtun fetch-as AS9009
#   sshtun fetch-country ru
#
# Принудительно в туннель (даже если адрес есть в исключениях):
#   sshtun include add 198.51.100.7

# --- примеры (удалите, когда будете добавлять свои) ---
# 203.0.113.0/24
# 198.51.100.7/32
